# Tasks
| **Task** | **Instruction** | **Justification** | **Estimated Time** |
|---------|-----------------|------------------|--------------------|
| User registration/login | Create a new user profile with secure credentials. | This task is necessary to test the user registration and login page for usability. We hope to figure out how easy it is to create a new user from the perspective of someone who has never used the app. | 3 minutes |
| Set up profile image and bio | Navigate to your profile page and personalize the profile picture and bio. | We want to test the intuitiveness of the profile UI in terms of updating your profile. | 3 minutes |
| Add friends | Search for and add your friends to your profile: “lara”, “victor”, “olivia”, “angela” | The user needs to be able to connect with friends in order to see their reviews on their feed and view friend profiles. | 5 minutes |
| View friend’s profile | Click on a friend’s profile | Test the functionality of clicking on a user’s profile and the interactive elements within it. | 2 minutes |
| Check feed | Navigate to the home page and scroll through the populated feed. | Test the user experience with scrolling down the feed, and if more/less information should be displayed to the user. | 3 minutes |
| Add comment on review | Leave a comment on an existing review | We aim to find out how intuitive the comment feature is on an existing review. This can be done several ways and we’d like to discover how the user completes this task. | 2 minutes |
| Search for song to review | Search for a song to review | We aim to test the ease of use of the search functionality, particularly with latency and search quality. | 1 minute |
| Review Songs | After searching for a song, leave a rating and review for it. | The review function is the core feature of our app. We want users to feel that it is easy and intuitive to leave a review on any song. Although the text portion of a review is optional, we want to test when/if users are inclined to leave a review beyond the numerical rating. | 5 minutes |
| Add songs to Favorites | Find some songs you’d like to add to your favorites playlist | Test how intuitive it is to add a song to the Favorites playlist. | 5 minutes |
| Add songs to Listen Later | Find some songs you’d like to add to your listen later playlist | We want to see how intuitive it is to add songs to listen to later. | 5 minutes |
| Update a review | Go to an existing review for a song, and modify your review. | Users may want to update reviews in the future. | 2 minutes |
| Delete a review | Go to an existing review for a song and delete it | Users may want to delete reviews in the future. | 1 minute |
| Review a song from listen later | Navigate to your listen later playlist and review a song that you previously added there | Test workflow from the listen later playlist to review | 2 minutes |
| Remove songs from favorites or listen later playlists | Remove a song from either your favorites or listen later playlist. | There are various ways to access the songs in the playlists and we hope to find out what the user prefers. This would allow us to make the app more intuitive in the future. | 2 minutes |
